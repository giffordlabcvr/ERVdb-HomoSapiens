# Lambdaretrovirus: U3

**U3** is an ERVdb-defined subgroup of *Lambdaretrovirus* within *Clade III*. It includes the human *HERV-U3* lineage and a non-human representative; the earlier ERVdb reference set identifies an equine U3 lineage.

U3 is treated separately from the L subgroup in the current classification. Here, U3 is the name of a lineage grouping, distinct from the use of U3 for a region of the retroviral long terminal repeat.
