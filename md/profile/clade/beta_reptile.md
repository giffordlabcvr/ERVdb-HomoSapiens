# Betaretrovirus: reptile grouping

The **reptile grouping** is an ERVdb-defined comparative unit for reptile-derived endogenous retroviruses assigned to the *Clade II* beta-related assemblage. The current reference set contains two non-human representatives.

Its host-associated label identifies the source of the included sequences; it does not establish that all reptilian beta-related elements belong to this grouping.
