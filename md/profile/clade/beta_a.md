# Betaretrovirus: A

**A** is an ERVdb-defined subgroup of *Betaretrovirus* within *Clade II*. The current endogenous reference set contains non-human representatives, with no human representative assigned to this subgroup.

Earlier ERVdb metadata places the murine IAPE reference, associated with intracisternal A-type particle elements, in subgroup A. This provides a named reference point for the grouping within the wider beta-related endogenous retrovirus radiation.
