# Zetaretrovirus: W9P

**W9P** is an ERVdb-defined subgroup of *Zetaretrovirus* within *Clade I*. Human representatives include the *HERV-W*, *HERV-9*, *HERV-P* and *HERV-30* lineages.

The grouping also includes non-human endogenous retroviral representatives. It provides a shared phylogenetic and alignment framework for comparing these lineages within the broader Zeta radiation.
