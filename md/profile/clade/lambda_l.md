# Lambdaretrovirus: L

**L** is an ERVdb-defined subgroup of *Lambdaretrovirus* within *Clade III*. It includes the human *HERV-L* lineage and related non-human endogenous retroviruses; the earlier ERVdb reference set includes murine *MuERV-L*.

The L grouping is distinguished from the U3 subgroup in the current ERVdb classification. This subdivision supports comparisons within each branch while retaining their shared placement in the broader Lambda assemblage.
