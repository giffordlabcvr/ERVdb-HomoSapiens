# Zetaretrovirus: HF

**HF** is an ERVdb-defined subgroup of *Zetaretrovirus* within *Clade I*. It brings together human lineages including *HERV-H*, *HERV-Fa*, *HERV-Fb* and *HERV-Fc*, alongside related non-human endogenous retroviruses.

The non-human reference set includes canine ERV-Fc. HF provides a comparative framework for examining this radiation across human and other host genomes, rather than treating the named human repeat families as isolated components of retroviral diversity.
