# Gammaretrovirus: LEU

**LEU** is an ERVdb-defined subgroup of *Gammaretrovirus* within *Clade I*. The grouping is currently defined by exogenous viral representatives; no endogenous representative has yet been included in its ERVdb reference set.

The absence of an endogenous reference is a statement about current database coverage and does not establish that related endogenous lineages are absent from host genomes.
