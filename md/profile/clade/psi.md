# Psi

**Psi** is an ERVdb-defined genus-level grouping currently represented by an endogenous retroviral sequence from an alligator. It is not currently recognised as a formal taxon by the ICTV.

The present reference set provides a single representative of the group. Its inclusion documents an additional component of retroviral diversity preserved in crocodilian genomes; broader conclusions about its host distribution and internal diversity await further characterisation.
